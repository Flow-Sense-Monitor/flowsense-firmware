# FlowSense — Firmware

Pasta reservada para o firmware do hardware físico, para quando o projeto for montado com os equipamentos reais:

- ESP32 DevKit V1
- Sensor de tensão ZMPT101B
- Sensor de corrente SCT-013-000
- Relé 5 V (1 canal), LEDs verde e vermelho, buzzer ativo e display OLED SSD1306

Por enquanto o FlowSense roda na simulação do Wokwi. O código usado na simulação está na pasta `wokwi/` do repositório principal.
